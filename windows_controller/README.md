# Windows 11 多安卓设备远程控制与批量管理终端指南

本目录包含专为 Windows 11 设计的现代化多安卓受控设备批量管理程序 (`win11_controller.py`)。

## 🌟 核心功能特性

1. **多设备并发管理与持久化**：
   - 支持同时添加、管理、监控多台安卓设备（手机、平板、安卓工控机）。
   - 自动保存设备列表、PIN授权令牌 (Token)、自定义备注到本地 `remote_devices.json`，下次启动免重新输入PIN。
2. **局域网一键快速扫描 (LAN Auto-Discovery)**：
   - 自动基于当前网段（如 `192.168.1.1 ~ 254`）并发扫描局域网内所有已开启受控服务的安卓设备，自动入库。
3. **PIN 码数字安全绑定**：
   - 安卓受控端屏幕生成 6 位随机数字密码，控制端必须输入正确 PIN 才能配对并接收控制权。
4. **设备信息自动回传与电量监控**：
   - 绑定成功后，受控端自动回传其 **IPv4 地址**、**MAC 物理地址**、**唯一序列号 (Serial)**、设备硬件型号、安卓版本、实时电池电量与充电状态。
5. **实时并发心跳状态**：
   - 多线程并发异步心跳检测，毫秒级响应，实时展示每台设备的 `🟢 在线 (电量/充电)` 或 `🔴 离线` 状态，某台设备断网绝不卡顿界面。
6. **批量多选与精准控制**：
   - 快捷按钮：**☑ 全选**、**☐ 取消全选**、**🟢 仅选在线设备**，或在列表双击/空格自由勾选特定设备。
7. **多设备批量命令下发**：
   - 🔔 **批量响铃**：一键让所有已勾选设备同时响铃 10秒、30秒，或立即批量停止响铃。
   - 🔦 **批量闪光灯**：一键让所有已勾选设备同时常亮、开启 10秒 警示爆闪 (Strobe) 或全部关闭。
   - 💬 **批量弹窗通知**：自定义标题与正文，群发全屏弹窗与系统级横幅通知到所有选中设备。

## 🚀 启动与运行方式

### 方式 A：Windows 11 双击启动 (推荐)
1. 确保 Windows 11 电脑已安装 Python 3.x（已内置 `tkinter`，无需使用 `pip` 安装任何第三方库）。
2. 双击运行 `run_win11_controller.bat`，即可打开多设备批量控制客户端。

### 方式 B：终端命令启动
在当前 `windows_controller` 目录下打开 CMD 或 PowerShell 执行：
```bash
python win11_controller.py
```

### 方式 C：单设备浏览器 Web 控制台
如果暂时不想运行 Python，也可直接在 Windows 11 的 Edge 或 Chrome 浏览器中访问任意一台受控手机的网址：
`http://<手机IP>:8888`，即可直接使用手机内置的单设备 Web 控制面板。

## 📖 多设备批量使用步骤

1. **准备受控设备**：
   - 将 1 台或多台安卓手机连接至与 Windows 11 电脑相同的 Wi-Fi 或热点。
   - 在各手机端打开应用并开启“受控服务”，记录各手机显示的 **IPv4 地址** 和 **6位数字 PIN 密码**。
2. **添加设备**：
   - **快速添加**：在顶部输入设备 IP、端口（默认 8888）、手机屏幕显示的 6 位 PIN 码以及自定义备注（例如：“库房手机A”、“展厅平板”），点击【➕ 绑定并添加设备】。
   - **局域网扫描**：点击【🔍 局域网快速扫描】，程序将并发扫描当前网段所有已开启服务的设备并自动加入列表。
3. **批量控制**：
   - 点击【☑ 全选】或【🟢 仅选在线】挑选需要控制的设备。
   - 点击【响铃 10秒】或【闪光灯爆闪】或输入文字点击【群发弹窗通知】，控制端将通过多线程并发向所有设备同时下发命令！
